bond-manager, screen by screen

bond-manager sets up and changes network bonds on RHEL servers through NetworkManager, and undoes a change by itself if it cuts you off. These are real screens from version 3.1, captured on a test server called web01. Pick a chapter, then step through with the buttons or the ← → keys.

    About these screens
    
      
    Captured from bond-manager 3.1.0 in a 100×34 terminal, running against test data. web01, its ports and its addresses are examples, and the countdown timers are frozen at the moment each screen was taken.
    
      
    Nothing runs in your browser. To try it for real without changing anything, start it in practice mode: sudo bond-manager -n
    
      
    Install, guide and source: https://github.com/i0mja/rhel-bond-manager
